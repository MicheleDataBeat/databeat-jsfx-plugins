# Shiro factory source credits

Every factory source in this instrument is CC0-1.0 ("public domain dedication"), which means the creators have waived their rights and no credit is legally required to use, modify or redistribute these recordings, including inside Shiro. We list the people and projects behind each sound anyway, because Versilian Studios and the individual recordists put real work into building these libraries and made a point of sharing them freely.

Nothing from Freesound is included in this factory pool. Some Freesound CC0 recordings were identified as candidates for evolving/environmental material, but Freesound requires a user account to download and none was created for this build, so none of those recordings were downloaded, prepared or shipped.
